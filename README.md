# Soundlight

A React Native mobile app for importing long-form audio tracks, visualizing waveforms, cropping timestamped excerpts, and attaching personal notes. Designed for keeping track of quotes, highlights, and key moments across audiobooks, lectures, podcasts, and music.

## Features

- **Audio Vault**: Import and manage local audio tracks with automatic track duration calculation.
- **Interactive Waveform Visualizer**: View track audio signatures and select precise timestamp regions for clipping.
- **Timestamped Excerpt Tagging**: Crop specific audio ranges and save them with attached notes or quotes.
- **Full-Text Excerpt Search**: Filter and search through saved excerpts and annotations across your entire library.
- **Integrated Playback**: Dedicated playback controls and excerpt management interface.
